⌨ Keyboard shortcuts (fully mouse-free entry)
  • Tab / Shift+Tab — next / previous field
  • Enter — pick the highlighted suggestion and move to the next field; on a plain field it just moves on; on the very last field (Discounted Price) it submits the form
  • ↓ / ↑ — move through Type 1 / Type 2 / Color / Province suggestions
  • Esc — close the current suggestion list
  • Ctrl/⌘+Enter — add a new color row and jump into its Type 1 field
  • Ctrl/⌘+Shift+Backspace — remove the color row you're currently in
  • Ctrl/⌘+Shift+L — toggle dark / light theme
  • Checkboxes: focus with Tab/Enter, toggle with Space (standard browser behavior)
